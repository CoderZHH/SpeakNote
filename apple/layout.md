# 原生界面布局规范

本轮仅调整页面结构与共享控件，继续使用已有 Swift Store、SQLite 记录和 CloudKit 协议。

## 共用规则

- 系统语义字号、颜色、辅助功能与深色模式；主内容使用系统背景，导航区域使用系统材质。
- Mac 页面留白 24、列间距 20、卡片圆角 12；紧凑页面左右留白 16，集合网格随可用宽度调整列数。
- 筛选使用轻量选中底色，不使用铺满灰色的多层分段背景。搜索集中为同一组件。
- 条目共用勾选、内容、已填写截止日期、备注和更多。Mac 的关联在标题右侧，手机放在标题下方的紧凑标签中，避免挤成一个字母或重复导航箭头。标题默认一行，长内容自然增高；隐藏创建日期。所属集合内不重复显示关联。
- 查看时内容是文本，轻点后原地编辑；提交/失焦沿用共有保存规则，失败保留输入。拍照字段继续显式取消/完成，不因失焦保存。思考继续自动保存。
- 备注一键展开，重要程度只影响小型操作控件，不染整条背景。

## 页面

| 页面 | Mac | iPhone / 紧凑窗口 |
|---|---|---|
| 今日 | 紧凑专注栏、有课才显示课程；任务约六成、记录约四成，各自滚动 | 专注与课程在上；任务/记录切换，内容占满宽度 |
| 拍照 | 左订单列表、右订单详情；固定工具栏保存操作；筛选与搜索集中在列表上方 | 列表进入详情，保留系统返回；键盘下确认可用 |
| 思考 | 左列表与标签筛选，右侧直接新增/编辑；正文顶部有可编辑标签 | 搜索、筛选、列表，新增与点入均进入完整编辑页；不重复页面大标题 |
| 项目 | 自适应一至三列卡片，待办直接展开、底部原地添加；已完成从按钮锚定弹层展开 | 单列相同卡片，可直接添加待办；标题进入完整详情 |
| 学习 | 复用项目卡片，同时展示未转成任务的学习步骤 | 相同卡片；完整层级在详情里管理 |
| 课程 | 七天共用时间轴，课程按起止时间定位；课程管理使用紧凑卡片 | 同一周网格，保留可读列宽，左右滑动看整周 |
| 日历 | 默认周视图，紧凑周/月切换 | 默认月与当日日程，保留专注时间修正 |
| 账号 | 平台、名称、打开后台、数据图标、更多组成紧凑行 | 沿用账号与作品数据入口，平台限制下不提供 Chrome 后台 |
| 设置 | 左对齐、最大内容宽度 720；同步、备份、折叠高级选项 | 同样分组，使用系统表单 |

## 共享组件位置

- `Features/WorkbenchDesign.swift`：搜索、筛选、面板和布局常量。
- `Features/ItemViews.swift`：任务/随手记行、行内编辑、备注、关联及操作。
- `Features/CollectionBoard.swift`：项目、学习卡片及共用稳定列布局。`Features/CourseCard.swift`：课程摘要及卡片操作。
- `Features/CourseBoard.swift`：学期排课数据与周课表。`Features/WeekTimeline.swift`：周课表与周日历共用的外框、日期栏、时间轴、事件块和缩放。

集合卡片按稳定的列顺序放置。完成内容在弹层内滚动，不扩张整张卡片，避免打开后其他卡片跳位。导航与弹层使用系统转场，遵循减少动态效果设置。

## 设计系统的实现约束

原生工程使用 SwiftUI，没有 CSS。`WorkbenchDesign` 是共用设计参数，页面容器与组件负责把参数实际应用到布局；不能只放一份常量而让各页继续自行拼接边距。

| 共用入口 | 负责的规则 | 接入范围 |
|---|---|---|
| `WorkbenchDesign` | Mac/手机页面边距、间距刻度、系统语义字号、背景/选中态、圆角、最小行高和表单宽度 | 共用界面代码 |
| `.workspacePage()` | 组合页面的唯一外层留白 | 今日宽屏、项目、学习、课程、账号 |
| `WorkspaceDetailPage` | 阅读详情的内容宽度、统一分组间距和滚动区域，字段不强制使用列表分割线 | 拍照订单详情 |
| `WorkspaceList` | 内容左右边距、原生选择区适配、最小行高、整行分割线 | 所有业务内容列表，包含详情、关联选择、作品数据、图片管理 |
| `WorkspaceEntrySheet` | 小型新建面板的标题、内容留白、取消/确认、键盘及保存中状态 | 任务、随手记、项目、学习、账号 |
| `.workspaceInput()` | 文本输入的内边距、背景、边框、焦点态 | 小型新建面板 |
| `.workspaceSheetForm(height:)` | Mac 复杂表单的分组样式、明确宽高及独立滚动区域 | 新建订单、课程、学期、上课安排、任务安排及专注修正 |

页面外层边距 Mac 24、手机 16；主从列表区域 16；间距刻度 8/12/16/20。Mac 最小行高 36、手机 44。标题与正文使用系统语义字号，不全局写死像素字号。

组合页面先使用 `workspacePage` 时，内部 `WorkspaceList(inset: 0)` 不再增加第二份外层留白；独立列表使用默认页面边距；主从列表明确使用 `masterInset`。macOS 原生列表额外的 8 点选择区内边距只在共用容器适配，业务页不做负边距补丁。

原生侧栏、系统分组 Form 和日历时间网格是不同的布局角色：侧栏由系统管理；分组 Form 的组内留白由系统管理；日历共用同一列宽计算。它们不通过在所有 View 上粗暴叠加 padding 来统一。

新增业务列表需通过 `apple/check-design-system.sh`；禁止重新直接使用裸 `List`。新建面板复用 `WorkspaceEntrySheet`；多字段表单复用尺寸适配。新增基础容器例外必须说明布局角色并更新此文档。

视觉验收至少检查：空内容、长文字、窄窗口、列表末行、键盘出现、取消不保存。编译成功不能替代实景检查。

## 导航与详情

- Mac 首次启动先显示微信助手引导。引导期间，弹窗背后只显示窗口背景，工作台导航和内容不加载。微信绑定并通过 DeepSeek API Key 验证后自动进入工作台，用户可在进入后试发待办。重新启动会续接已保存的配对进度。完成过引导的用户直接进入工作台，仍可从侧栏打开微信助手。

- 模块顺序：今日、拍照、思考、项目、学习、日历、课程，最后为账号和设置。手机使用原生 TabView 的今日、拍照、思考、项目、更多五个入口；更多中按顺序显示学习、日历、课程、账号和设置，均使用同一个 NavigationStack，避免系统自动 More 导航与页面导航叠加。
- 项目、学习、课程卡片使用同一个 `CollectionChecklist`，直接显示全部未完成待办与添加框。卡片与详情复用 `CollectionTaskEntry`，输入可换行，点击加号创建并关联所属集合。附件通过待办行的共用入口添加，归属该待办。
- 项目、学习卡片只有底部输入框旁的一个添加按钮；标题栏保留备注与更多。
- 课程详情只显示一份课程标题和已填写的教师/学期；上课安排合并星期、时间、教室、教学周，不重复本周课程。待办原地添加，备注在后。
- 拍照详情不使用“更多信息”折叠。截图操作紧邻图片；拍摄要求、邮费/佣金和备注直接显示。备注只有一个编辑入口；取消/完成沿用固定工具栏。

- 月历使用 `MonthCalendar` 的七列网格，与周视图共用周一开头、Asia/Shanghai 日期规则；不能用 `.graphical` DatePicker 充当整页月历。宽屏为整月网格与当日列表双栏，紧凑宽度为月历上、日程下；月份/导航/周月切换共用一个自适应栏。
- 月历标记与当日列表均使用 `calendarEntries`，继续显示计划、课程、完成与满足十分钟阈值的专注；未设时间的待办列为全天。没有日程时显示一条空态，不保留空分组标题。网格的星期、日期使用同一列宽。

- 快速添加统一使用 `WorkspaceComposerLayout` 与 `WorkspaceSubmitButtonStyle`：输入框和按钮采用同一测量高度；长文本增高时按钮同步增高。Mac 单行最小高 40、手机 44；空内容时按钮为低对比度，输入有效内容后使用强调色。
- 拍照详情使用 `WorkspaceDetailPage` 阅读容器：品牌在最上方，进度与截止日期紧凑同行，大字号下允许自然分行。截图与拍摄要求宽屏并列、窄屏上下排列；费用和备注直接显示，取消大块空值灰卡。推进状态操作固定在底部系统工具区域，正文滚动不带走操作。
- 订单名称只在正文摘要显示一次，详情导航栏保留返回和操作，不重复名称。

- 专注统一使用 `FocusPresentation` 与轻量 `FocusTimerState`。iPhone 灵动岛/锁屏显示任务名称、正计时与暂停状态；点击返回今日。Mac 只在当前专注存在时显示菜单栏时间，弹出暂停/继续、结束和打开主窗口。系统入口不每秒读取/写入 SQLite，不给主页面增加常驻状态说明。

- 任务安排复用原生日期/时间控件，在结束时间后放置一个“提醒”开关；默认关闭，未开启具体时间时不可用。提醒按开始时间发送，不再叠加提前时间选择。重新进入面板须还原完整时间及提醒状态；权限或保存失败在面板内保留输入。

- 思考新增与已有内容共用 `ThoughtEditor` 和 `ThoughtEditing`：Mac 宽屏在右侧直接写，手机/窄窗口走原生导航；今日入口以完整编辑页呈现。这个界面属于长文编辑区，不使用小型 `WorkspaceEntrySheet` 多行输入弹窗。
- 标签在编辑区顶部常驻，支持已用标签多选、自定义新增及直接移除。反思/思维/认知是预置标签，允许零到八个标签，沿用共享标签校验；自定义标签参与列表筛选与搜索，筛选精确匹配标签。
- 空白新增不写数据库、退出不留空条目；正文首次输入后使用稳定 UUID 自动创建。正文/标签通过同一缓冲区串行保存，切换页面或前后台时等待正在进行的保存；失败保留输入并允许重试，不另设草稿箱。

- 新建任务继续使用 `WorkspaceEntrySheet`：名称和选填备注在上，关联、五级颜色重要程度、安排组成紧凑属性行。只填名称可添加，重要程度默认为最低，安排默认为今日且不设具体时间/提醒。重要程度不显示等级文字或要求输入数字。
- 新建与已有条目复用 `AssociationSelectionPicker`、`TaskImportanceChoices` 和 `TaskScheduleEditor`。新建中的子面板只修改本地表单值，取消子面板保留原选择；最终“添加”才一次提交完整任务。取消主面板不创建任务，错误在主面板中显示并保留输入。
- `TaskScheduleValues` 集中负责时间还原、校验与提醒语义；新建任务在最终提交前申请通知权限。任务关联仍指向原项目/学习/课程 UUID，不创建副本；集合内可见的是同一任务。

- 三点操作复用 `WorkspaceMoreMenu`，触发按钮只显示图标，菜单项显示图标和文字。工具栏自定义菜单使用 primaryAction 与隐藏菜单指示符，触发按钮的纯图标样式限定在按钮标签。普通次要 Button 可继续交给系统收纳。
- 订单图库按内容宽度分页、完整适配截图比例；Mac 预览高 400，手机按视口计算 300–560 的有界高度，不用正文尺寸反复驱动布局。手机品牌/进度/日期固定在顶部，推进状态固定在底部，中间滚动。多图有页码；截图操作只有一组图标，无图只有一个添加入口。
- 手机原图查看使用 UIKit 原生分页和缩放容器，双击/捏合缩放、放大后拖动看图；原尺寸下向下拖动跟手退场，未达到阈值轻缓复位。关闭和辅助功能退出入口保留；遵循减少动态效果。图片后台解码限制到 4096 像素，只维护当前与相邻页面，不把全相册原图放入 SwiftUI State。Mac 沿用系统 Quick Look。
- 订单截止日期查看时为紧凑日期，编辑时使用原生可选日期控件；原地编辑仍由固定取消/完成显式提交。推进状态保存中禁用重复点击，失败留在当前页并在底部操作区显示错误。

- 手机今日、拍照、思考、项目/学习的新建入口共用 `phoneCreateAction`，固定在底部便于触及，列表末项仍能滚动至可操作区域。Mac 继续使用工具栏入口。今日根页面隐藏空导航栏，进入关联详情后恢复系统返回路径；集合导航由模块宿主共用路由处理，不由行控件重复声明目标。
- 新建订单及详情修改截止日共用 `OptionalDateField`：默认无日期，开启后用系统 DatePicker；关闭恢复未设置。只填品牌可建单。
- 新任务与随手记的新建附件复用 MediaPicker，支持照片/视频与文件选择；表单只持有暂存文件的元数据，不持有所有附件 Data。最终添加在同一数据库事务中提交条目、关联属性、附件和同步日志；失败回滚数据库并清除本次复制的文件，暂存材料保留供重试，稳定 UUID 避免重复。取消关闭暂存入口并清理文件，不生成任务或草稿。

- 条目操作统一使用锚定三个点按钮的 `ItemActionPanel` 原生 popover。重要程度色板必须是可直接渲染的 SwiftUI 内容，不再放入系统 Menu / ControlGroup 的纯图标行，避免 Mac 转换菜单项时出现整排空白。五个色点默认灰色最低；选中项同时显示勾与外圈，无需输入数字，也不增加五段等级文字。新建与已有任务复用 `TaskImportanceChoices`。
- 重要程度在今日/以后、项目、学习、课程的任务投影中共用 `taskImportanceOrder`：级别降序，同级按创建时间和 UUID 稳定排序。只改变同一任务的 importance；不复制任务，不改变关联。小型操作按钮与非逾期截止日期使用同一等级色，逾期未完成任务日期仍用红色；整条不铺彩色背景。
- 操作面板点击后先关闭，再执行动作或展示关联/安排；避免多个原生弹层同时争夺展示。保存成功后由共用 Store 刷新，失败保留原数据并显示错误。

- 思考仍以单份 content 保存：第一段使用系统 title2 加粗，其后使用 body；回车与光标位置决定后续输入字号。标题与正文属于同一原生 UITextView/NSTextView，连续选择、粘贴、撤销不拆成两个字段；组合输入期间不重排文字。列表标题取字面第一行，不跳过空行冒充正文为标题。标签与自动保存继续复用原缓冲区，无数据库迁移。
- 今日“记录 → 项目/学习”直接复用 CollectionCard，默认展开未完成待办（学习包含未转任务的步骤），底部保留 CollectionTaskEntry。今日、集合模块及详情指向同一任务 ID 与关联；不使用只有名称的跳转行代替展开内容。已完成内容继续在独立弹层中查看，避免卡片高度跳动。

- 手机条目备注编辑时在输入框旁显示“完成”，共用行内保存逻辑。其他行内编辑与集合快速输入沿用键盘工具栏。思考使用顶部导航栏的“完成”，确认组合输入并收键盘，继续统一自动保存。
- 课程详情使用 WorkspaceDetailPage：课程名称、教师、学期组成摘要。上课安排、待办和课程备注各自分组。课程备注在待办下方，复用 ItemRemarks；这里的附件归课程，单条待办的附件仍从该条待办添加。备注编辑使用系统粘贴操作，图片沿用现有附件缩略图和预览。
- MediaPicker 的系统菜单只放普通按钮，照片选择器通过独立 photosPicker presentation 打开，文件入口继续 fileImporter；不能把 PhotosPicker 控件嵌入原生 Menu。附件导入显示进行中并阻止重复触发；成功刷新并安排同步。只有附件没有文字也视为有备注，条目和集合图标显示已填状态。

- Mac 专注菜单栏只使用 AppKit FocusStatusItemController（NSStatusItem / NSMenu）。图标创建时设置一次，每秒只更新原生文字；状态变更才更新菜单内容/停启唯一 Timer，结束移除状态项并清空菜单。禁止把 FocusTimerText 或其他动态 SwiftUI 标签放入 MenuBarExtra。菜单栏对象归 App 持有，窗口只观察专注投影；关闭窗口不会生成另一计时器。

## 手机列表与设置（2026-10-30）

- 主 Tab 根页面隐藏空导航栏，搜索/筛选紧接系统安全区域，不保留重复标题或空工具栏。进入详情显式恢复系统导航栏与返回按钮，项目/思考的新建及订单原地编辑仍保留确认操作。“更多”内的二级页面保留返回路径和紧凑标题。
- 主从选择仅属于 Mac 双栏；拍照/思考的手机和单栏列表不绑定 selection，不自动选第一项，也不沿用桌面选中底色。返回列表保留原筛选和滚动位置。
- 手机拍照列表不放共享管理按钮；WorkBench 在更多 → 设置 → 拍照共享空间管理。拍照助手使用订单、拍摄、设置三个原生 Tab；设置不展示个人工作区备份/导入导出。
- 设置/拍照共享共用 workspaceSettingsForm：手机采用系统分组表单与背景，首组顶部间距 8、组距 20；Mac 最大宽 720 并左对齐。同步摘要、同步动作、共享入口分别成行，长错误不挤进按钮所在横行；版本与存储路径放在关于与存储，备份动作直接可见。

- 思考保存失败提示归入标签下方的编辑内容区，采用语义图标、可换行说明和重试，不在键盘/Tab 上方另铺悬浮条。思考的“完成”固定为导航栏确认操作；正文仍自动保存，组合输入确认后再收键盘。
- 思考自动保存以 SQLite 事务实际写入的正文和标签为基线。首尾空白的规范化不改变编辑中的输入，也不构成冲突。真正内容不一致时保留本地输入，通过“核对版本”比较并选择；保存本机输入仍核对用户刚看过的已保存版本。

- 拍照订单存在共享冲突时，在详情正文顶部提供“核对修改”入口，比较界面默认展开差异；不把操作藏在设置中。当前未提交输入保留，核对后仍需点完成。订单字段无冲突可本地保存，但整条订单待核对后才继续上传；冲突字段必须显式选择。
- 核对只决定有分歧字段的取舍，自动保留双方不冲突的改动；没有三方基线时仍按完整版本谨慎选择。确认必须验证最新 revision，避免核对期间的新输入被过期按钮覆盖。

## 同步版本比较与防重复（2026-11-10）

- 同一记录的相同内容、完成时间差异和可确认的正常拍照进度推进自动合并；旧冲突在打开工作区时按同样规则整理。不同 UUID 的同名条目不能仅凭名称合并。
- 个人版本比较显示实际字段差异，支持保留当前、使用保留版本以及显式保留两份。使用保留版本沿用原 UUID；有三方基线时只替换有分歧的部分。只有显式保留两份才建立新条目，重复确认不再建立第二个副本。
- 个人与拍照比较在保存中禁用重复操作；版本过期时刷新比较并保留处理入口。旧格式内容保留可复制正文和单份导出入口，不让一份旧记录阻塞整个工作区。
- 比较区沿用系统分组 Form、共享间距、语义字号和可换行文本；长文在当前/保留两个纵向区域展示。空状态不显示多余的核对分组。

## 微信任务安排与独立提醒（2026-11-10）
